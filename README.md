Pet Shop Website 🐾

This project is a Pet Shop Website built using Spring Boot, Thymeleaf, and Spring Security. It is designed to provide a platform for managing and showcasing products catering to the needs of various animals, including food, medicine, and accessories.

Features ✨

💼 User Management:

Users can register and create their own accounts.

Secure login and authentication powered by Spring Security.

🐈 Product Management:

Showcase products for different animals, including medicines, food, and accessories.

🔄 Dynamic Content Rendering:

Uses Thymeleaf for rendering dynamic web pages.

💡 Future Enhancements:

Planning to integrate new technologies and improve features like order management, payment gateway integration, and advanced search filters.

Technologies Used 🛠️

Backend Framework: Spring Boot 3.3.1

Frontend: Thymeleaf Templates

Security: Spring Security for authentication and authorization

Database: MySql

Build Tool: Maven

Installation and Setup 🚀

Requirements:

Java 17+

Maven 3.8+

IDE (IntelliJ IDEA, Eclipse, etc.)
